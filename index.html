Record schema

Structured, not a raw dump.

Every post is one line of gzipped JSON Lines. The Threaded edition adds three fields; the cleaned corpus carries the first six. Nothing else differs between them.

  "id": "msg-4c9f1a\u2026e07b",
  "group": "comp.lang.c",
  "date": "14 Mar 1991 09:22:41 GMT",
  "author": "[email]",
  "subject": "Re: pointers vs. arrays",
  "text": "Not quite. An array name decays\u2026",
  "thread_id": "8f3c\u2026d2",
  "thread_position": 4,
  "thread_depth": 2
}
idstringStable per-post id — msg- + SHA-256 of the original Message-ID.
groupstringNewsgroup the post was archived under.

thread_idstringConversation identifier. Threaded edition.

Provenance & data quality

How the record was built.

A deterministic, fully logged pipeline from raw MBOX archives to delivered corpus. Every transformation is documented; every claim is verifiable.

01

Hierarchy exclusions

alt.binaries.* and adult groups removed entirely before record-level work — negligible NLP value, high noise.

02

Binary detection

MIME inspection for residual UUencoded and base64 payloads; records carrying binary content dropped.

03

PII redaction

Email addresses replaced with an [email] token throughout; Message-IDs replaced with SHA-256 hashes.

04

Language detection

Every record tagged with fastText LID-176 — 96.6% English across 100+ languages, so subsets can be filtered by language.

05

Thread reconstruction

Conversation trees rebuilt from References headers into 191.7M threads with per-post position and depth.

06

Cross-post measurement

Duplication measured, not hidden: 343.6M distinct posts (15.8% cross-posted), retained and labeled by shared id.

0

Malware-clean — by the same scanner your pipeline runs.

A two-stage ClamAV pass — per-post signature scanning plus whole-file span localization for multi-part payloads — removed every signature match, concentrated in the security and warez groups. The delivered corpus passes a whole-file ClamAV scan with zero detections, and every removal is logged. No raw Usenet dump can say the same.
